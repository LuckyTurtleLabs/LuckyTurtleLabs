# LuckyTurtle Labs

Independent lab running two things at once: a live multi-coin mining
operation, and autonomous agentic engineering tooling that lands real
open-source contributions.

## Mining — still live

**LuckyTurtle Harbor** — multi-coin solo-mining harbor with dedicated
tiny-ASIC and ASIC lanes.

- Coins: **DGB, BTC, BCH, BTCS**
- Live pool telemetry and tenant frontends at
  [luckyturtle.io](https://luckyturtle.io)
- Public repo:
  [`luckyturtle-harbor`](https://github.com/LuckyTurtleLabs/luckyturtle-harbor)

## Engineering — what we're doing now

We build and operate a local-first autonomous agent platform that
discovers, evaluates, builds, tests, and ships real contributions to
open-source projects — including bug-bounty work.

Recent public work:

- PRs and review threads across
  [EdgeChains](https://github.com/arakoodev/EdgeChains/pull/286),
  [Dokploy](https://github.com/Dokploy/dokploy),
  [Coolify](https://github.com/coollabsio/coolify), and others

The heavy machinery stays private; the output is public.
